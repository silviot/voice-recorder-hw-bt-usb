# Allocation-failure sweep waivers (tests/bt_host/run_sweep.py --mode M --waivers; make test-bt-host).
#
# Format: mode  function[<-caller]  CLASS  COUNT  reason        (mode = init | enable | disable | deinit)
# Only the lines of the swept mode apply. A waiver names an UPSTREAM Bluedroid site whose allocation failure is not
# handled and that has no documented patch (third_party/bluedroid_patches, plan M1 "general rule"). A waived point is
# reported as WAIVED and does not fail the gate; any other CRASH / HANG / CHECK does. COUNT is the exact number of
# sweep points the waiver covers: more matches fail the run (a new failing path ending at a waived site), fewer print a
# warning (fixed or stale: lower the COUNT or drop the line). NOT_INJECTED points can never be waived.
#
