### 1.3 `[Critical]` Stall/link-loss seek formula (`acked_sbc × 128` minus `lat_pcm`, §4.6 / §6.1) corrupts file position, and `queued_frames` (§4.4) breaks `player.c` invariants
- **Stream-counter vs file-offset mismatch:** [BT_A2DP_DESIGN.md:384-385](file:///home/silvio/dev/voice-recorder-hw-bt-usb-bt/docs/BT_A2DP_DESIGN.md#L384-L385) and [BT_A2DP_DESIGN.md:490-491](file:///home/silvio/dev/voice-recorder-hw-bt-usb-bt/docs/BT_A2DP_DESIGN.md#L490-L491) seek the player to `acked_sbc × 128` (converted to `src_rate`) minus `lat_pcm`. Worse, `queued_frames` ([BT_A2DP_DESIGN.md:340](file:///home/silvio/dev/voice-recorder-hw-bt-usb-bt/docs/BT_A2DP_DESIGN.md#L340)) **already includes `down_sbc`**, so `player_heard_frames()` (`played_frames - queued_frames`, [player.c:317-322](file:///home/silvio/dev/voice-recorder-hw-bt-usb-bt/open_fw/src/player.c#L317-L322)) already excludes unacknowledged `down_sbc` packets.

(2) After `aout_flush()` (where `g_dac_buf` is empty), unconditional `+ lat_pcm` (~150 ms) plus pause-silence packets in flight keep `queued_frames > 0`, making `player_pause_rewind()` ([player.c:808](file:///home/silvio/dev/voice-recorder-hw-bt-usb-bt/open_fw/src/player.c#L808)) walk backwards on repeated Play/Pause, paused seeks ([player.c:851](file:///home/silvio/dev/voice-recorder-hw-bt-usb-bt/open_fw/src/player.c#L851)) drift backwards by `lat_pcm`, and `scrub_heard()` ([player.c:361-374](file:///home/silvio/dev/voice-recorder-hw-bt-usb-bt/open_fw/src/player.c#L361-L374)) underflow `submitted < queued`.

### 1.6 `[Critical]` `SBC_Encoder_Init()` clobbers `s16BitPool = 0`, and Stage-1 resampler overflows Q32 on 48 kHz -> 44.1 kHz
- **`SBC_Encoder_Init()` overwrites `s16BitPool`:** [BT_A2DP_DESIGN.md:254-255](file:///home/silvio/dev/voice-recorder-hw-bt-usb-bt/docs/BT_A2DP_DESIGN.md#L254-L255) sets `SBC_ENC_PARAMS` fields including `s16BitPool` and calls `SBC_Encoder_Init()` without mentioning `u16BitRate`. In [sbc_encoder.c:227-271](file:///home/silvio/dev/voice-recorder-hw-bt-usb-bt/open_fw/third_party/bluedroid/host/bluedroid/external/sbc/encoder/srce/sbc_encoder.c#L227-L271), `SBC_Encoder_Init()` **ignores the caller's `s16BitPool`** and recomputes it from `u16BitRate` — with `u16BitRate == 0`, `s16Bitpool` goes negative and is clamped to **`s16BitPool = 0`**! `s16BitPool` must be assigned *after* `SBC_Encoder_Init()`.
- **Q32 phase-step overflow:** [BT_A2DP_DESIGN.md:161](file:///home/silvio/dev/voice-recorder-hw-bt-usb-bt/docs/BT_A2DP_DESIGN.md#L161) specifies *"linear interpolation, Q32 phase step `src/conn`"*. When playing a 48 kHz WAV over a 44.1 kHz SBC fallback link (SEID 1, [BT_A2DP_DESIGN.md:234-236](file:///home/silvio/dev/voice-recorder-hw-bt-usb-bt/docs/BT_A2DP_DESIGN.md#L234-L236)), `48000 / 44100 = 1.088435` overflows `uint32_t` `0.32` fixed point to `0.088435` (~1/12th speed). Needs `uint64_t` (`32.32`) phase accumulation.

### 1.7 `[Critical]` Cross-mode `bt_store` RAM contamination locks out the user's bonded phone (§6.3, §6.4)
`bt_store` ([bt_store.c:21-32](file:///home/silvio/dev/voice-recorder-hw-bt-usb-bt/open_fw/bt_port/bt_store.c#L21-L32)) is a single static RAM buffer across the boot, and `bt_port_init()` ([bt_port_glue.c:98-105](file:///home/silvio/dev/voice-recorder-hw-bt-usb-bt/open_fw/bt_port/bt_port_glue.c#L98-L105)) has `static int done; if (done) return 0;`, latching the first mode's `s_store_flush` callback forever. On the next Phone mode entry, §6.3's rule (*"phone mode: everything except addresses in `bt_hp_bonds.bin`"*, [BT_A2DP_DESIGN.md:528](file:///home/silvio/dev/voice-recorder-hw-bt-usb-bt/docs/BT_A2DP_DESIGN.md#L528)) **rejects the user's own bonded phone!** (Also note `/bt_hp_bonds.bin` is a `BTS1` NVS container wrapping an INI blob `"bt_cfg_key0"`, not a raw BD_ADDR table.)

### 1.8 `[High]` Just Works without patch 0032 bypasses both `ssp_block` entropy gating and `ssp_burn` P-192 key-spend protection (§6.3, §15.2)
[BT_A2DP_DESIGN.md:531-532](file:///home/silvio/dev/voice-recorder-hw-bt-usb-bt/docs/BT_A2DP_DESIGN.md#L531-L532) claims entropy gating and P-192 key-reuse protection work *"as in phone mode (`ssp_block`... `ssp_burn`; `on_cfm_req`)"* while deferring patch 0032 to "Phase 2" ([BT_A2DP_DESIGN.md:518-521](file:///home/silvio/dev/voice-recorder-hw-bt-usb-bt/docs/BT_A2DP_DESIGN.md#L518-L521), [BT_A2DP_DESIGN.md:867](file:///home/silvio/dev/voice-recorder-hw-bt-usb-bt/docs/BT_A2DP_DESIGN.md#L867)). 1. If TRNG/mic entropy is starved or the P-192 key is already burned (`ssp_block() == true`), Bluedroid still completes ECDH + confirmation using the ROM's unreplaced/burned key before post-hoc `AUTH_CMPL` runs.

## 4. What I Would Do Differently (Ranked by Impact)

1. **Eliminate the 7.7 KB `hold_pcm` buffer (§4.3):** In `hp_tx_tick` ([BT_A2DP_DESIGN.md:282-290](file:///home/silvio/dev/voice-recorder-hw-bt-usb-bt/docs/BT_A2DP_DESIGN.md#L282-L290)), check `txq_pkts < TXQ_PKT_CAP` *and* allocate `buf = esp_a2d_audio_buff_alloc(...)` (`!= NULL`) **before** popping/resampling PCM from `g_dac_buf`. If `esp_a2d_source_audio_data_send()` fails (`tx_flush` race), free `buf`. Saves **5.6–7.7 KB of critical main `SRAM`** and simplifies `queued_frames` / `is_busy`.
2. **Patch `bta_av_do_close()` for fast local disable (like patch 0026) and deinit AVRCP *before* A2DP (§5.5):** When `bta_av_cb.disabling == TRUE` in [bta_av_aact.c:1618-1625](file:///home/silvio/dev/voice-recorder-hw-bt-usb-bt/open_fw/third_party/bluedroid/host/bluedroid/bta/av/bta_av_aact.c#L1618-L1625), skip `AVDT_CloseReq` + the 4 s timer and complete local stream teardown immediately after `esp_avrc_tg_deinit()` / `esp_avrc_ct_deinit()`. Then `clean_up()` ([btc_av.c:2153](file:///home/silvio/dev/voice-recorder-hw-bt-usb-bt/open_fw/third_party/bluedroid/host/bluedroid/btc/profile/std/a2dp/btc_av.c#L2153)) always runs in <50 ms with zero leaks and clean `.bt_bss` state on frozen peers.
3. **Track monotonic `written_real_pcm` vs `heard_real_pcm` instead of `acked_sbc` file seeks (§4.4, §4.6):** Count real source-rate frames pushed since `aout_start`/`aout_flush` (excluding pause silence and underrun pads), clamp `aout_queued_frames() <= unacked_real_pcm` (`0` after `aout_flush()`), and snapshot `queued_frames` *before* flushing/rebasing on Remote SUSPEND, stall, or link loss. Then [player.c](file:///home/silvio/dev/voice-recorder-hw-bt-usb-bt/open_fw/src/player.c)'s existing `player_pause_rewind()` (`played_frames - aout_queued_frames()`) works identically across `resume_sec`, seeks, scrub, pause, and multi-file playback with zero special-case seek math.
4. **Move H4 (`bt_session_core.c`) ahead of H3 and make the Just Works `CFM_REQ` patch (`0034` on [btc_dm.c:581](file:///home/silvio/dev/voice-recorder-hw-bt-usb-bt/open_fw/third_party/bluedroid/host/bluedroid/btc/core/btc_dm.c#L581)) mandatory in v1:** Gives Exp 4b real P-192 key staging + `bt_rom_rng` + `ssp_block`/`ssp_burn` from day one, clears `bt_store` unconditionally before loading per-mode bond files, and replaces the single-shot `s_store_flush` latch in [bt_port_glue.c:98-105](file:///home/silvio/dev/voice-recorder-hw-bt-usb-bt/open_fw/bt_port/bt_port_glue.c#L98-L105).
5. **Drop AVRCP TG `PLAY_STATUS_CHANGE` / `TRACK_CHANGE` RN from v1 (§5.4, §6.6):** Keep TG Passthrough (`PLAY`/`PAUSE`/`FORWARD`/`BACKWARD`) + CT Absolute Volume (`EVENT_VOLUME_CHANGED` / `SetAbsoluteVolume`), which *are* implemented in [btc_avrc.c](file:///home/silvio/dev/voice-recorder-hw-bt-usb-bt/open_fw/third_party/bluedroid/host/bluedroid/btc/profile/std/avrc/btc_avrc.c), avoiding a large custom patch to `btc_avrc.c` for metadata headphones never display.
6. **Escalate stalled-credit recovery to full `bt_ctrl` reset if `0x05` does not arrive within ~1 s (§4.6), and stop `hp_tx_tick` on `BTC_TASK` (§4.3):** Posting `btm_remove_acl()` on `BTU_TASK` followed by a 1 s timeout into full controller reset cleanly recovers both normal RF drops and ROM H2 ghost links (`LC state == 0`), while cancelling/freeing the `osi_alarm` inside a `BTC_TASK` callback eliminates any timer-generation race.
